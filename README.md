# Coding Practice – 10 Python Programs

## Objective

This repository contains 10 Python programming problems completed to improve basic programming logic and problem-solving skills.

## Programs Included

1. Even or Odd Number
2. Largest of Three Numbers
3. Prime Number Check
4. Fibonacci Series
5. Factorial of a Number
6. Reverse a String
7. Palindrome Check
8. Count Vowels in a String
9. Sum and Average of List Elements
10. Find the Second Largest Number

## Technology Used

* Python
* Visual Studio Code
* GitHub

## Learning Outcome

Through these programs, I practiced basic Python concepts such as conditional statements, loops, strings, lists, mathematical operations, and user input.
